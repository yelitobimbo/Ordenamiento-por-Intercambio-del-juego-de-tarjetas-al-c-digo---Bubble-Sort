 #  Práctica: Ordenamiento por Intercambio con Tarjetas metodo Burbuja

Repositorio que contiene la solución para la práctica de estructuras de datos y algoritmos de ordenamiento, desarrollada en pseudocodigo y java

## Contenido del Repositorio
* **`OrdenamientoTarjetas.psc`**: Pseudocódigo inicial basado en la lógica de tarjetas físicas y casillas de memoria.
* **`OrdenamientoBurbuja.java`**: Implementación en Java del método burbuja (`bubbleSort`), incluyendo pruebas con arreglos desordenados, ordenados e inversos, además del conteo de pasadas, comparaciones e intercambios.
* **Documento de la Práctica**: Archivo de Word con el registro de la simulación, respuestas y conclusiones.
